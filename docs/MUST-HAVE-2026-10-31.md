# Project Journey · MUST HAVE · 31. oktober 2026

Autoriseret af Patrick. Alle 12 punkter bevares, selv om bestillingen kalder dem 10. Arbejd i rækkefølge med intro først. Dette dokument er første GitHub-gemning før kodeændringer.

## Fast designretning
Bevar WOBS-inspireret blomme/lilla, rosa, varm creme og sidens nuværende typografi. Introens bund er mørkere lilla, aldrig sort. Brug eksisterende, faktiske projektbilleder og originale assets. Sammenhængende venstrekant og læsbar tekst; hele ord må aldrig splittes visuelt. Bevægelse skal fortælle om projekterne og reagere meningsfuldt. Ingen opdigtede produktstatusser. NEURO og WOBS først. Portfolio er en separat hjemmeside og må ikke redigeres.

- [x] 3. MENU i versaler, nyt hover-ikon fremfor plus, åbning ved hover på desktop samt klik/touch/tastatur. Juster til sidens venstrekant.
- [x] 4. Fjern Leg med ordene helt.
- [x] 5. Giv hjernens afsluttende fragmentering et færdigt, sammenhængende visuelt udtryk.
- [x] 6. Projektbåndet skal bruge originale logoer hvor de findes og være genveje til de fire projekters sektioner.
- [x] 7. Farvede ord skifter automatisk uden hover. Flere relevante formuleringer på tværs af sektioner.
- [x] 8. NEURO: samme størrelse og effekter som øvrige projekter, rigtige designbilleder i arbejds-/statusvisningen fremfor generiske skitser.
- [x] 9. Fjern overflødige lokale Pause-knapper, bevar hover-pause og reduceret bevægelse.
- [x] 10. Opdag/Discover skal have en levende, produktiv interaktion med tydeligt resultat.
- [x] 11. Om mig får flere relevante skiftende ord/formuleringer.
- [x] 12. Erstat FORTSÆT med meningsfuld afslutning, der fortæller at ideerne fortsætter og leder til en konkret handling.
